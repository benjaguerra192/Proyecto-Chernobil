# CHERNOBYL 360° VR Gallery

Una experiencia de Realidad Virtual inmersiva construida con **A-Frame**, diseñada para explorar la histórica sala de control del Reactor 4 de Chernobyl.

## 🚀 Características
- **Inmersión Total**: Escenas 360° de alta resolución con efectos visuales dinámicos.
- **Audio Atmosférico**: Sistema de audio inteligente con *ducking* (el ambiente baja cuando hablan los operarios).
- **Interacción Pro**: Sistema de hotspots dinámicos, paneles informativos y navegación fluida.
- **Modo VR**: Compatible con Google Cardboard, Oculus/Meta Quest y dispositivos móviles.
- **Efectos Visuales**: Simulación de radiación (glitch de UI, temblor de cámara y contador geiger).

## 🛠️ Tecnologías
- [A-Frame](https://aframe.io/) - Framework de Realidad Virtual para la web.
- [Three.js](https://threejs.org/) - Motor 3D subyacente.
- **HTML5/CSS3/JS** - Arquitectura modular personalizada.

## 📦 Instalación y Despliegue
Este proyecto es 100% estático. Para visualizarlo localmente o desplegarlo:

1. Clona este repositorio.
2. Abre el archivo `index.html` en un navegador (se recomienda usar un servidor local como *Live Server* para evitar bloqueos de CORS en los audios).
3. Para desplegar en **GitHub Pages**: Sube los archivos y activa la opción en `Settings > Pages`.
